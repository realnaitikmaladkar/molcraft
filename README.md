# MolCraft - Chem & Mole Workbench

MolCraft is a fast, browser-based chemistry workbench built for students, teachers and science enthusiasts to explore chemical equations and stoichiometry without any setup or logins. Designed specifically for learners, it turns complex chemical balancing and unit conversions into an interactive visual experience. Users can balance arbitrary chemical equations in milliseconds, inspec atom-byatom conservation of mass, and calculate molar masses for everything from simple compounds to multi-part hydrates. It also features a complete 118-element interactive Periodic Table and a built-in Balance Practice Quiz to test stoichiometry skills. Everything runs 100% client-side with zero backend latency.
